# ERP-MPS辅助决策仿真智能体
信管专业ERP课程期末作业｜基于Streamlit开发的MPS主生产计划智能体网页仿真系统
> 场景升级：零碳工业园区算电协同仿真，融合虚拟电厂、分时电价、碳配额交易

## 📖项目简介
本项目面向零碳工业园区，构建MPS主生产计划调度智能体，实现生产、电力、碳排的协同优化（算电协同）。
- 仿真粒度：168小时（连续7天逐小时仿真）
- 系统要素：逐小时分时电价、园区光伏、储能电池、动态碳配额与碳价、虚拟电厂需求响应
- 生产约束：多品种产品、订单交付期限、设备产能上限、换产工时与成本、原材料库存、成品仓储、设备故障扰动
- 智能体：贪婪启发式调度Agent，支持电费与碳排放双目标权重调节
- 对比实验：基准场景（无光伏、储能、碳交易）VS优化场景，量化经济收益、碳减排效果

## 🧮核心模型
1. 生产模型：产能约束、工时上限、订单交付约束、原料库存、换产成本、成品仓储成本
2. 电力模型：光伏出力时序仿真、储能充放电模拟，优先消纳绿电，减少电网购电
3. 虚拟电厂：需求响应事件，削减生产负荷获取补贴
4. 碳核算模型：产品工艺直接碳排放+外购电力间接碳排放；光伏自发自用不计碳；碳配额超额后碳价随超额量动态上涨
5. 综合成本公式：
综合总成本 = 购电电费 + 换产成本 + 仓储成本 + 碳交易成本 − 需求响应补贴
