# ERP-MPS辅助决策仿真智能体
> 信管专业ERP课程期末作业：基于Streamlit开发的MPS主生产计划智能体网页仿真系统

## 项目简介
本项目面向中小型离散装备制造工厂，构建多层智能体嵌入ERP五大计划中的MPS主生产计划模块，实现**算电协同**排产优化。
用户可在网页界面自定义工厂产能、订单、分时能耗参数，智能体自动完成工时分配、能耗核算、方案对比与风险评估。

## 技术栈
Python + Streamlit + Pandas
无需本地安装软件，直接访问网页链接即可使用。

## 使用方式
访问项目网页链接，在左侧面板输入业务参数，点击运行，即可查看排产方案、能耗结果。
